# ヤラカシログ

## サイト概要
### サイトテーマ
失敗談に特化したコミュニティSNS
### テーマを選んだ理由
私自身、友人との食事や飲み会などで、終電の時間を勘違いして焦ったり、帰りの交通手段に困ったりした経験があります。そのようなときに事前に他の人の失敗談や体験談を知っていれば、同じような失敗を防げたのではないかと思います。
また、こうした日常のちょっとした「やらかし」は、誰かに話すと笑い話になりますが、同じ失敗を防ぐための情報として共有される機会は少ないと考えました。
そこで、日常生活で経験した失敗談を気軽に投稿し、他のユーザーがその経験から学べるSNSを作りたいと考え、このテーマを選びました。
### ターゲットユーザ
・10～30代のちょっとした失敗をしたことがある人

・失敗談を人と共有するのが好きな人

### 主な利用シーン
・自分が失敗してしまった時

・何かをする前に他の人の失敗を参考にしたい時

・暇な時間に他の人の失敗談を見たい時
